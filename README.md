# Голосовой ответ 3.0

Полноценное приложение-телефон для Android: журнал звонков, контакты, набор номера и красивый
экран входящего звонка, которым можно управлять **голосом**.

## Что умеет

- Экран звонка с кнопками «Принять» / «Отклонить» и голосовым управлением.
- Говорите **«принять / ответить / ответ»** — берёт трубку; **«отклонить / отмена / сбросить»** — сбрасывает.
- Свои слова: Настройки → «Слова-команды» → добавьте, например, «персик».
- После голосового ответа включается громкая связь на 100% (каждое можно отключить в настройках).
- Наушники подключены → разговор идёт в наушники, динамик не включается.
- Озвучивает, кто звонит («Звонит Мама»).
- Цвета: синий, красный, фиолетовый, зелёный, оранжевый, розовый, бирюзовый, радужный, свой; фон чёрный / тёмный / светлый.
- В фоне ничего не работает и не светится: система сама запускает приложение только на время звонка.

## Новое в 3.20

- Настройки → «Входящий звонок»: показ **на весь экран** или **окном сверху** (на разблокированном телефоне), нарастающий рингтон с выбором времени.
- Набор номера: окно с вставкой/копированием номера, кнопка «в контакты», больше подсказок.
- Настройки → «Цвета телефона»: темы фона (новогодняя, зимняя, летняя, весенняя, осенняя, своя картинка) и прозрачность панелей.
- Вибрация в начале и конце разговора; в журнале вызовов показана длительность разговора.
- Карточка собеседника (кнопка «i» в журнале и нажатие на контакт): все номера, дата и время звонка и 5 последних звонков.
- Голосовые команды распознаются чувствительнее: быстрее реагируют на короткие слова и узнают их с другими окончаниями.
- Иконка приложения — стандартная телефонная трубка.
- Запись разговоров из приложения убрана: её ведёт стандартное приложение «Телефон».

## Как собрать APK (GitHub)

1. Залейте содержимое папки в репозиторий на GitHub (ветка `main`).
2. Вкладка **Actions** → «Build APK» запустится сама (или Run workflow).
3. Готовый файл — в **Releases → VoiceAnswer (последняя сборка) → VoiceAnswer.apk**
   (а также в артефактах запуска).

## Первый запуск

Подробная инструкция есть в приложении: Настройки → «Инструкция». Коротко:
1. Установите APK (Play Защита может предупредить — «Подробнее → Всё равно установить»).
2. Откройте приложение → «Разрешить» (все разрешения).
3. «Сделать основным» → выберите «Голосовой ответ» как приложение для звонков.
4. Батарея → «Без ограничений», на TECNO: Диспетчер телефона → Автозапуск.
5. Настройки → «Проверить» — скажите слово и убедитесь, что оно слышно.

Вернуть обычный телефон: Настройки Android → Приложения по умолчанию → Приложение для звонков.

## Как устроено

- `CallService` (InCallService) — Android включает её только пока есть звонок.
- `Calls` — список звонков, ответ/отбой, маршрут звука, озвучка звонящего.
- `InCallActivity` — экран звонка; `VoiceListener` слушает слова, пока экран виден.
- `Logic` — слова-команды и вспомогательная логика без Android (покрыта тестом).
- `MainActivity` / `SettingsActivity` — интерфейс; `Theme`, `Ui`, `Views` — оформление.

## Ограничения

- Android 8.0+. Нужны Google-службы распознавания речи (приложение «Google»).
- Микрофон слушает, только пока виден экран входящего звонка (если свернуть — не слушает).
- Громкая мелодия может заглушать голос — есть настройка «Тихий рингтон».
- Микрофон Bluetooth-наушников — по возможности, зависит от модели.
- Экстренные вызовы (112) через набор номера работают как обычные звонки.
